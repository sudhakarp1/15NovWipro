Logging is recording/writing events that happen when your program/application is running.
These events can be used while debugging(debug info), warnings, error or system info

Logging is defined to control the severity of message. Critical error are more severe than debug messages.

Level		Purpose
--------------------
DEBUG		Detailed information for debugging
INFO		General messages (program is running)
WARNING		Something unexpected but not fatal
ERROR		Something failed, program can continue
CRITICAL	Severe error, program may crash

File Handling:
--------------
Files are data stored in external memory. 
	Basic operations 
		1. open a file: bringing the data from the file into the memory referred by the handle(file object)
		2. read data: read function is used to read from file object into the variable(basically a string)
		3. write data:write function is used to write from variable(text) to file object
		4. close/flush:  data referred by the file object is now transferred to the disk(external file)
			
	fileObject = open(filename, mode)
		fileObject.read ()
		fileObject.write()
	fileObject.close()
	
		or
		
	with open(filename, mode) as fileObject:
		//perform file operations
		//Context manager
		
	mode:	
		'r' 	-> read 
		'w' 	-> write (truncate/overwrite if existing file) 
		'a' 	-> append  
		'x'  	-> create new file (error if file exists)
		'r+'  --> read + write 
		'w+' -->  write + read 
		'a+' --> Append + Read
		
		'b' --> binary
		't' --> text
